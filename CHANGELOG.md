# Changelog

## 1.0.0

First release.

- Generate text from a prompt or straight from the selection, at the cursor, on a
  new line, or replacing the selection.
- Generate an image from a prompt or the selection, saved in the vault and
  embedded in the note.
- Sign in with the device flow: a short code, approved in the browser, with no
  secret baked into the plugin. An API key can be pasted instead.
- Any model from the live text and image model lists, with a browser to search
  them from inside Obsidian.
- Retries with backoff and a plain-language message per failure kind.
